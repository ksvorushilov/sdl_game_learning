# SDL Game Learning

A small C game project built for learning SDL and game-loop fundamentals. The project implements a classic Snake game in two different rendering backends: SDL and ncurses.

## Overview

This repository is meant as a learning project for:

- C programming and game state management
- SDL2 windowing and rendering
- input handling
- game loops and timing
- basic collision detection
- project organization with multiple source folders and a Makefile

## Features

- Snake game gameplay
- Menu screen and game state transitions
- Food spawning and score-style progression
- Wraparound toggle option
- SDL and ncurses implementations
- Build support through a Makefile

## Project structure

- `src/` - core game logic and platform-specific source files
- `include/` - public headers and shared types/constants
- `build/` - compiled object files generated by the build
- `bin/` - final executable output
- `Makefile` - build configuration

## Build

From the project root, run:

```bash
make sdl
```

Or for the ncurses version:

```bash
make ncurses
```

To run the built binary:

```bash
./bin/app.exe
```
